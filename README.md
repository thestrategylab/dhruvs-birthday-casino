# Dhruv's Birthday Casino 🎰

15 drinking games for one legendary night. A retro-casino party app — add up to
15 players, pick a table, and let the house run the game. Sips are the currency.

**Play it:** open the GitHub Pages link on your phone → Share → **Add to Home Screen**
→ it installs like an app and works fully offline.
